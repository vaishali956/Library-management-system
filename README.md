# Library Management System

A full-stack **Library Management System** built with **Node.js** backend and **React.js** frontend.  
This project allows managing books, users, transactions, fines, and reports in a library environment.

---

## 🗂 Project Structure
Library-management-system/
├── library-frontend/ # React frontend
│ ├── src/
│ ├── public/
│ ├── package.json
│ └── package-lock.json
├── backend/ # Node.js backend (API + DB)
├── README.md
└── ...



---

## ⚙ Features

- Add, update, and manage books
- Manage library users and memberships
- Book issue, return, and availability tracking
- Fine calculation and payments
- Admin and user dashboards
- Reports for transactions, fines, and issued books
- Authentication with login system

---

## 💻 Technologies Used

- **Frontend:** React.js, CSS, HTML  
- **Backend:** Node.js, Express.js, MongoDB  
- **Tools:** Git, npm
